# Contributing to Tokey

Thanks for your interest in improving Tokey. This repository is an **issue tracker only** — there is no code here to contribute to directly.

## How You Can Help

### Filing Good Issues

The most valuable contribution you can make right now is a well-written bug report or feature request.

**A good bug report includes:**
- Exact steps to reproduce (numbered list)
- What you expected vs. what actually happened
- Your environment (OS, Node version, browser if applicable)
- Error messages and stack traces

**A good feature request includes:**
- The problem you're trying to solve (not just the solution)
- Why existing behaviour falls short
- Any alternatives you've considered

### Issue Etiquette

- **Search before filing** — duplicates slow everyone down
- **One issue per report** — don't bundle multiple bugs together
- **Stay on topic** — keep discussion focused on the original issue
- **Be respectful** — we follow the [Contributor Covenant](https://www.contributor-covenant.org/)

## Issue Lifecycle

| Status | Meaning |
|---|---|
| `triage` | Newly filed, not yet reviewed |
| `confirmed` | Reproduced and accepted |
| `in progress` | Actively being worked on |
| `blocked` | Waiting on external dependency |
| `wontfix` | Out of scope or intentional |
| `duplicate` | Already tracked in another issue |

Issues without sufficient information to reproduce or evaluate may be closed after 14 days of no response.
